Luffy para Linux

Esta distribuição inclui o runtime VLC/libVLC e seus plugins. Não é preciso
instalar VLC separadamente.

Requisito: Java 21 instalado (OpenJDK 21 ou equivalente).

Para iniciar:
  bash Luffy

Ou, para deixar o iniciador executavel e iniciar normalmente:
  chmod +x Luffy
  ./Luffy

Use sempre o lançador ./Luffy: ele localiza o VLC integrado e ajusta as
bibliotecas nativas antes de abrir o aplicativo.

Não execute o arquivo .jar usando ./Luffy-0.1.0-linux.jar: ele não é um
binário Linux e, ao iniciá-lo diretamente, o VLC integrado não será localizado.

Esta versão contém as bibliotecas nativas JavaFX e VLC para Linux x86_64,
empacotadas e validadas no Ubuntu 24.04. Em outras distribuições, use uma
versão compatível com glibc do Ubuntu/Debian.
Integração com magnet e .torrent
--------------------------------

Após extrair a pasta, execute uma vez:

  sh install-desktop-integration.sh

Isso registra o Luffy como uma opção para links magnet: e arquivos .torrent
somente para o usuário atual. O script não altera o aplicativo padrão; escolha
Luffy em “Abrir com” ou nas configurações do navegador/ambiente gráfico.
