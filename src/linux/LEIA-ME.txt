Luffy para Linux

Requisito: Java 21 instalado (OpenJDK 21 ou equivalente).

Para iniciar:
  bash Luffy

Ou, para deixar o iniciador executavel e iniciar normalmente:
  chmod +x Luffy
  ./Luffy

Tambem e possivel iniciar diretamente:
  java -jar Luffy-0.1.0-linux.jar

Nao execute o arquivo .jar usando ./Luffy-0.1.0-linux.jar: ele nao e um binario Linux.

Esta versao contem as bibliotecas nativas JavaFX para Linux x86_64.
